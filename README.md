# Registro fotográfico

Aplicación web sencilla para guardar fotografías con título, fecha y descripción.
Los registros se almacenan en `localStorage` del navegador y permanecen en el
dispositivo donde se agregaron.

## Estructura

```text
registro-fotografico/
├── index.html
├── css/
│   └── estilos.css
├── js/
│   └── app.js
└── README.md
```

## Uso

Abre `index.html` en un navegador moderno, completa el formulario y selecciona
una imagen. Las tarjetas guardadas se pueden eliminar desde la galería.

No se requiere instalación ni servidor. Como los datos se guardan localmente,
no se sincronizan entre navegadores o dispositivos. El espacio disponible
depende del navegador y del tamaño de las imágenes.
